What is NabzAI?

NabzAI is an independent project that produces short fictional live-action style films with AI video generation, neural narration and automatic editing. Every video is clearly labelled as synthetic / AI-generated media.

How it uses YouTube

NabzAI uses the YouTube Data API only to upload videos and thumbnails to the project owner's own YouTube channel. It does not access, read or modify any other user's account or data.
