Privacy policy

Last updated: October 3, 2026

This policy describes how the NabzAI application ("NabzAI", "we") handles information when it is authorized to access a YouTube account.

Who can use NabzAI

NabzAI is a private, single-owner automation tool. It is used only by its owner to publish videos to the owner's own YouTube channel. It is not offered to the public.

Data we access

NabzAI requests only the youtube.upload permission. It uses this permission solely to upload video files, titles, descriptions, tags and thumbnails to the authorized channel. It does not read, collect, store or share any personal data, viewing history, comments, subscribers or analytics.

Storage of credentials

The OAuth access token is stored as an encrypted secret in the owner's private build environment and is never shared with third parties.

Google API Services

NabzAI's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. NabzAI also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account permissions.
