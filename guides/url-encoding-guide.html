راهنمای کاربردی

URL Encoding چیست و چه زمانی به آن نیاز داریم؟

راهنمای URL Encoding و Decoding برای متن فارسی، فاصله‌ها، پارامترها و لینک‌های وب.

URL Encoding چیست؟

بعضی کاراکترها در URL معنای خاص دارند یا ممکن است در انتقال مشکل ایجاد کنند. URL Encoding آن‌ها را به شکل مناسب برای قرارگرفتن در URL تبدیل می‌کند.

متن فارسی و فاصله

در پارامترهای URL ممکن است متن فارسی و فاصله‌ها به صورت percent-encoded نمایش داده شوند. این رفتار طبیعی است و به معنی خراب‌شدن متن نیست.

Encode یا Decode؟

اگر می‌خواهید متن را برای قرار گرفتن در URL آماده کنید، Encode مناسب است. اگر یک رشته encoded دارید و می‌خواهید مقدار خوانا را ببینید، Decode استفاده کنید.

احتیاط

هر بخش URL قواعد مخصوص خود را دارد؛ قبل از تغییر یک URL پیچیده، ساختار مسیر و query parameterها را حفظ کنید.
